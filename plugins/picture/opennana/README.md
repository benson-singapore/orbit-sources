# OpenNana Prompts

AI 提示词画廊插件，数据来源 [opennana.com](https://opennana.com)。

支持浏览 ChatGPT / Grok / Nano Banana Pro / Nano Banana 2 等模型生成的图片与视频，以及完整提示词。

## 频道

| ID | 说明 |
|---|---|
| image-all | 全部图片 |
| image-chatgpt | ChatGPT 图片 |
| image-grok | Grok 图片 |
| image-nano-banana-pro | Nano Banana Pro 图片 |
| image-nano-banana-2 | Nano Banana 2 图片 |
| video-all | 全部视频 |
| search | 关键词搜索 |

## 接口

- 列表: `GET https://api.opennana.com/api/prompts`
- 详情: `GET https://api.opennana.com/api/prompts/{slug}`
