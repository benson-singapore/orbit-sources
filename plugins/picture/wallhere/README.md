# Wallhere Plugin

Wallhere 壁纸插件，提供免版权高清壁纸浏览、搜索及分页功能。

## 功能特性

- **最新壁纸**：按发布时间排序的最新作品
- **热门壁纸**：按热度排序的热门作品
- **随机壁纸**：随机推荐
- **关键词搜索**：支持搜索功能
- **分页浏览**：完整的分页支持，可浏览所有内容

## API信息

- 网站：https://wallhere.com
- 无需API密钥
- 支持多语言路由（中文、英文等）
- 支持过滤参数（颜色、NSFW等）

## 数据来源

数据来自 Wallhere 网站，通过HTML解析获取。每个壁纸包含：

- ID、标题、图片URL
- 分辨率（宽x高）
- 标签信息
- 用户名
- 点赞数和收藏数

## 使用示例

最新壁纸、热门壁纸等频道无需配置，直接选择即可浏览。

搜索频道需要输入搜索关键词。

## 技术栈

- Go 1.22
- goquery - HTML解析库
- Orbit Plugin SDK
